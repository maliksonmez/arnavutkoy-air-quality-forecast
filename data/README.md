# Data

The raw data is **not** stored in this repository.

1. Go to the SİM station data download page: https://sim.csb.gov.tr/STN/STN_Report/StationDataDownloadNew
2. Select station **İstanbul – Arnavutköy**, period **16.09.2023 – 16.09.2026**, hourly data, pollutants **PM10, PM2.5, SO2, NO2**.
3. Download the Excel file (downloaded on 16 October 2026 for this project).
4. Upload it when a notebook asks for it (`files.upload()` in Colab).

File used: `İstanbul - Arnavutköy_16.09.2023-16.09.2026_Hava Kalitesi - İstasyon Veri İndirme_Detay.xlsx`
